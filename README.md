# Sonu Singh — Portfolio

Responsive single-page portfolio built with plain HTML, CSS, and JavaScript.

## Run locally

Open `index.html` in a browser, or run:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Included

- Responsive portfolio, skills, experience, and contact sections
- Project cards across AI, mobile/SaaS, Unity, and XR
- Project category filters
- Project Lab with four client-demo build ideas
- Scroll navigation and reveal animations
- No framework or build step required

## Important

Project statuses are labelled as development, concept, prototype, or initiative where applicable. Update descriptions and add public demo/repository links as projects become available.

## Structure

- `index.html` — page content
- `style.css` — responsive styles
- `script.js` — navigation, reveal animations, and project filtering
